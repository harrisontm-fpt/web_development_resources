# Restaurant Web Application Project

## Project Objective

The objective of this project is to build a functional restaurant-themed application consisting of:

- A **web application**
- An **ordering and pickup system**

---

## Minimum Web Application Requirements — Grade 1

The web application must include the following features:

### Core Pages

- **Home page**
- **Administration page**
- **Administrator login**

### Menu Management

- Functionality for **editing the food/lunch menu**
- A **restaurant menu**
- A **daily/weekly food or lunch menu**
  - Menu data must be retrieved as **JSON from your own API**.
  - The **current day's menu** must be highlighted in some way.
    - For example, if today is Wednesday, Wednesday's menu should be visually highlighted.

### Pricing and Dietary Requirements

- Pricing must be **clearly displayed**.
- **Special dietary requirements** must be taken into account.

### Open API Integration

The application must include some additional information relevant to the restaurant or its location, retrieved from an **open API**.

For example:

- Display relevant **HSL public transport information**.
- Use the **HSL Routing API** to provide transport or route information.

---

## Minimum Ordering/Pickup System Requirements — Grade > 2

To achieve a grade **higher than 2**, the ordering/pickup system should include **all minimum web application requirements** listed above, plus the following:

### Customer Features

- **Customer login and registration**
- **Shopping cart**

### Administration

- **Administration page**
- **Administrator login**
- Functionality for **editing the menu**
- **Order management**
